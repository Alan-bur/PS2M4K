## About
This project aims to prevent PS2 Menu from pixelating on modern screens. It works for PC only and it can't be loaded by a real PS2 since this console does not support 4k Textures. Everything has been remade and polished with new textures so you can now enjoy exploring the PS2 Menu on newer screens.

## Installation
1. Download the [latest release](https://github.com/Alan-bur/PS2M4K/releases/latest/download/replacements.zip).
2. Move the replacements.zip folder into C:\Users\your_user\Documents\PCSX2\textures\your_bios_folder.
4. Extract the replacements.zip folder. Right click → Extract all → Extract.
5. Set Graphics API to the latest Direct3D you have. Go to PCSX2 Settings → Graphics → Display
6. Enable Borderless Fullscreen and set Aspect Ratio to "Fit to Window / Fullscreen". Go to PCSX2 Settings → Graphics → Display.
7. Set Internal Resolution to 4x Native. Go to PCSX2 Settings → Graphics → Rendering.
8. Enable Load Textures. Go to PCSX2 Settings → Graphics → Texture Replacement.
11. Everything ready to play! 🫧☺️
